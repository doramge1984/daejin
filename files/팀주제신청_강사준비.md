# 「팀 주제 신청함」 템플릿 만드는 법 (강사 준비, 연수 전 1회 · 약 15분)

교수님들은 이 템플릿을 **복사**만 합니다. 강사가 한 번 만들어 두면 됩니다.

## 1. 템플릿 시트 만들기 (개인 구글 계정)
1. sheets.new → 제목: `팀 주제 신청함 (템플릿)`
2. 확장 프로그램 → Apps Script → 프로젝트 이름: `팀 주제 신청함`
3. `코드.gs`의 기존 내용을 지우고 `팀주제신청_코드.gs` 전체를 붙여 넣기 → 저장
4. 왼쪽 파일 목록 `+` → HTML → 이름을 **`index`** 로 (확장자 없이) → `팀주제신청_index.html` 전체를 붙여 넣기 → 저장
5. 위쪽 함수 선택에서 `처음준비` → 실행 → 권한 허용 → 시트로 돌아가면 탭 세 개(시작하기·주제목록·팀 명단)가 생김
6. 쓰지 않는 기본 탭 `시트1`은 삭제
7. 시작하기 B2 과목명은 `[가상] 캡스톤디자인`으로 둠 (교수님들이 바꿈)

## 2. 복사 링크 만들기
1. 오른쪽 위 공유 → 일반 액세스: **링크가 있는 모든 사용자 · 뷰어**
2. 링크 복사 → 주소 끝의 `/edit?usp=sharing` 를 `/copy` 로 바꿈
   예) `https://docs.google.com/spreadsheets/d/(문서ID)/copy`
3. 이 주소를 웹교안 탭3 · 4 심화의 「여기서 시작해요」 자리에 버튼으로 넣기
4. 시트 사본에는 Apps Script도 같이 복사됩니다. 배포는 복사한 사람이 각자 합니다.

## 3. 체험용(강사) 배포
1. 템플릿을 **한 번 더 복사**해 강사 체험용으로 씀 (템플릿 원본에는 응답을 쌓지 않음)
2. 웹교안 1부 4~8단계대로 배포 → 주소를 크롬으로 열고 QR 만들기 → 웹교안 「먼저 체험해 보기」 자리에 QR 이미지
3. 리허설: 휴대폰 2대로 같은 주제를 동시에 눌러 늦은 쪽에 마감 안내가 나오는지, 사진이 B5 폴더에 저장되는지 확인
4. 캡처: 1·3·5·8단계 화면에 빨간 네모 → 웹교안 `[강사 준비] 캡처` 자리 교체

## 확인할 것
- 대진대 PC실에서 script.google.com 접속, “확인되지 않은 앱” 진행이 막히지 않는지
- 학교 계정으로 복사하면 6단계에 ‘모든 사용자’가 안 보일 수 있음 → 개인 계정 안내
- 동시 등록은 LockService로 한 팀씩 처리 (리허설로 확인)
