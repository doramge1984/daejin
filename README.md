# 대진대 교수연수 웹교안 · 깃허브 업로드용 최종 (2026-11-01)

## 구성
- `index.html` 홈: 오전반 · 오후반 카드, 아래에 오후반 2부(심화) 카드
- `am-basic.html` 오전반 교안 (홈에서 연결하는 오전반. `am_이전.html`과 같은 내용에 홈·오후반 버튼만 추가, `assets/` `files/` `img/`를 씀)
- `pm.html` 오후반 교안 (1~5단계, 4·5단계 심화). 왼쪽 목차의 오전반 버튼 → `am-basic.html`, 1부 끝 "2부 교안으로" → `pm2.html`
- `pm2.html` 오후반 2부 · 수업 쌍방향 웹페이지(포스트잇 보드) 교안. 위쪽에 홈·오전반·오후반 버튼
- `강사보드/`, `demo/` 2부 시연용 보드
- `am.html` 오전반 새 교안 (작업 중, 홈에서 연결하지 않음)
- `am_이전.html` 이전 오전반 교안 원본 사본 (홈에서 연결하지 않음)
- 바꾸기 전 index·pm·README는 `대진대/_백업_20261030/`에 보관

1. 이 폴더 안의 파일 전체를 저장소 최상위에 올리기 (폴더째가 아니라 안의 파일들)
2. Settings → Pages → Branch: main, 폴더: /(root) → Save
3. `https://아이디.github.io/저장소이름/` 이 홈으로 열리면 성공
