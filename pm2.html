② 파이어베이스 연결 30분

  
파이어베이스는 구글이 만든 무료 데이터 저장소(창고)입니다. 포스트잇을 여기에 저장하면 모든 사람의 화면에 실시간으로 나타납니다.

  
오늘은 이렇게 해요창고를 직접 만드는 과정은 강사가 화면으로 보여 드리고, 교수님들은 강사가 미리 만들어 둔 연수용 창고에 내 보드를 연결합니다. 내 수업에 실제로 쓰실 때는 아래 ②+ 내 창고 만들기를 따라 교수님 계정에 창고를 만들어 옮기시면 됩니다.

보안 규칙 (규칙 탭에 통째로 붙여 넣기)
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /boards/{boardId} {
      allow read, write: if true;
      match /notes/{noteId} {
        allow read: if true;
        allow create: if request.resource.data.text is string
                      && request.resource.data.text.size() > 0
                      && request.resource.data.text.size() <= 200
                      && request.resource.data.likes == 0
                      && request.resource.data.hidden == false;
        allow update: if request.resource.data.diff(resource.data).affectedKeys().hasOnly(['likes', 'hidden']);
        allow delete: if true;
      }
    }
  }
}

    
누구나 읽고 쓸 수 있지만, 200자 넘는 글과 공감 수 조작은 막고 기한도 없는 수업용 규칙입니다. 그래도 주소를 아는 사람은 글을 쓸 수 있으니 이름·연락처 같은 개인정보는 받지 마세요.

제미나이에게 고쳐 달라고 말하는 법
    
  • "안 돼요" 대신 어디서 → 지금은 → 원하는 것: "붙이기 버튼을 누르면(어디서) 포스트잇이 안 보이고 화면이 그대로야(지금은). 누르자마자 보드에 새 포스트잇이 나타나게 해 줘(원하는 것)."
    • 
    
  • 오류 글자가 보이면 그대로 복사하거나 화면을 캡처해서 "이 오류를 고쳐 줘"
    • 
    
  • 고쳤더니 다른 곳이 망가지면 캔버스 위쪽의 이전 버전으로 돌아가고, 요청을 더 작게 나누기
    • 
    
  • 부탁하지 않은 곳까지 바뀌면 "○○은 그대로 두고 △△만 바꿔 줘"

  
auth/admin-restricted-operation 오류가 나요
익명 로그인이 꺼져 있습니다. ②+ 5단계대로 Authentication → 로그인 방법 → 익명 → 사용 설정 → 저장 하세요.

  
permission-denied 또는 missing or insufficient permissions 오류가 나요
규칙이 막혀 있습니다. 프로덕션 모드로 만들고 규칙을 안 바꿨거나, 테스트 모드 30일이 지난 경우입니다. ②+ 4단계대로 규칙을 통째로 바꾸고 게시하세요. 규칙을 바꿨는데도 나면 제미나이에게 규칙을 붙여 주고 "이 보안 규칙에 맞게 코드를 고쳐 줘"라고 부탁하세요.

  
파이어베이스에 들어가지지 않아요 / 권한이 없다고 나와요
학교 계정으로 로그인되어 있을 가능성이 큽니다. 크롬 프로필을 개인 Gmail로 바꾸거나 시크릿 창에서 개인 Gmail로 로그인하세요.

  
캔버스에선 되는데 파일로 열면 저장이 안 돼요
  • 익명 로그인을 켰는지 확인 (Authentication → 로그인 방법에 '익명 · 사용 설정됨')
  • 규칙을 바꾸고 게시했는지 확인 (②+ 4단계, 내 창고를 쓰는 경우)
  • firebaseConfig를 내 것으로 정확히 붙였는지 확인 (따옴표·쉼표 빠짐 주의)
  • 부탁문 ② 마지막 줄("다른 Firebase 설정이나 실행 환경 변수는 쓰지 말고")을 넣었는지 확인

  
파일을 열었더니 화면이 비어 있어요
메모장에서 붙여 넣을 때 코드 일부가 빠졌을 수 있습니다. 크롬에서 F12 → Console의 빨간 글씨를 복사해 제미나이에게 "이 오류를 고쳐 줘"라고 붙여 넣으세요. 급하면 길 B 완성본을 쓰세요.

  
넷리파이 주소에 들어가면 'Page not found'가 나와요
폴더 안 파일 이름이 index.html인지 확인하고 폴더째 다시 끌어다 놓으세요.

  
비밀번호를 바꾸고 싶어요
길 B 완성본은 메모장에서 const PASSWORD = "daejin1234";를 바꿔 저장 후 넷리파이에 다시 올리세요. 길 A는 제미나이에게 "비밀번호를 ○○로 바꿔 줘"라고 부탁하세요.
